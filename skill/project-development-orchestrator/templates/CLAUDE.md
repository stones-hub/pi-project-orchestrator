# Claude Code Entry

开始工作前按顺序读取：

1. `AGENTS.md`：项目长期规则、测试和授权边界；
2. `HANDOVER.md`：当前真实状态、已验证内容和下一步；
3. `docs/` 中与当前任务相关的已确认方案；
4. 当前 `.pi/tasks/<task-id>.md` 任务书。

以仓库文件和当前 Git 状态为真源。任务书中的 Risk、Scope、Verify 及允许/禁止
范围是硬约束；发现前提错误或范围冲突时停止并报告，不擅自扩大范围或修改已确认
方案。

你负责正式业务代码、测试及被明确授权的配置修改；Pi 负责最终独立检查、重跑
测试和本机候选业务验收。你自己的测试结果属于输入证据，不等于候选已验收通过。

不得读取或输出凭证；不得未经明确授权执行 commit、push、部署、SSH、生产访问，
也不得用 rsync、scp、docker cp 或其他方式向目标机器传递项目代码。
